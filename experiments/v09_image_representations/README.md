# v09_image_representations — 이미지 표현 비교 (분포 피처 vs CNN)

## 목적
이미지만으로 단계를 얼마나 맞히나, 표현별 비교. 그리고 센서 모델에 붙였을 때.

## 코드
- `image_repr.py` (인자 없이 실행 = 이 버전 비교)
- `common/thermal.py`: `rich_features()`, `RICH_FEATURES` 64개 (이 버전에서 추가)
- 캐시: `~/yeonwoo/work_imgrep/rich_*.npy`, `cnn_*.npy` (ResNet18)

## 결과
| 이미지만 | 피처 | CV | Val |
|---|---|---|---|
| A 퍼짐 | 13 | 0.697 | 0.663 |
| B 분포 | 64 | 0.706 | 0.672 |
| **A+B** | 77 | **0.734** | 0.694 |
| ResNet18 | 512 | 0.722 | 0.690 |

| 센서+열퍼짐에 더하기 | CV | Val |
|---|---|---|
| (기준) | 0.876 | 0.775 |
| + B 64 | 0.881 | 0.744 |
| + ResNet18 PCA 32 | 0.878 | 0.752 |

## 결론
이미지만으로 0.70~0.73. 센서에 그대로 붙이면 CV 오차 범위, Val 하락.
