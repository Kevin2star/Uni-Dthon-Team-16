# v11_stacking_temporal — 스태킹(이미지 확률 6개) + 임베딩 시간 변화

## 목적
768차원을 그대로 붙이지 않고 ① 이미지 모델의 6단계 확률만 넣기(스태킹), ② 30·60초 전 프레임과의 임베딩 변화 / 실제 경과 시간.
**중첩 CV**: 평가 실험은 이미지 모델·최종 모델 학습 모두에서 제외.

## 실행
`python -u stack_temporal.py | tee stack_temporal.log` (약 8분), `python viz_stack.py stack_temporal.log`

## 결과
| | CV | Val | Val S4 / S5 |
|---|---|---|---|
| 센서만 | 0.868 ± 0.031 | 0.760 | 0.55 / 0.61 |
| **+ 이미지 확률 6** | **0.873** ± 0.036 | **0.790** | **0.63 / 0.72** |
| + 임베딩 시간 변화 | 0.866 ± 0.032 | 0.773 | 0.56 / 0.63 |
| + 둘 다 | 0.873 ± 0.039 | 0.797 | 0.64 / 0.73 |

## 결론
스태킹이 유일하게 Val 개선(+0.029, 4·5단계). CV는 오차 범위(5 fold 중 4개 ≥). 임베딩 시간 변화는 효과 없음.
