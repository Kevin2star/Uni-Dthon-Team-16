# v06_monotone_postproc — 단조 후처리 비교

## 목적
"단계는 내려가지 않는다"를 이용한 후처리. 목표는 역행 0이 아니라 Macro F1.
원래 예측 / 누적 최댓값 / 확률 기반 단조 경로(전체 시퀀스, 분석용) / 확률 기반 단조 경로(과거만, 제출 가능).

## 실행
`python monotone_eval.py model_image_lgbm model_lgbm` (30초). 원래 예측·확률·후처리 결과를 CSV로 보관.

## 결과 (열 퍼짐 + LGBM)
| 방식 | OOF CV | Val | OOF 실험 개선/악화 |
|---|---|---|---|
| 원래 | 0.877 | 0.775 | – |
| 누적 최댓값 | 0.876 | 0.764 | 23 / 21 (최대 −0.14) |
| 전체 경로(분석용) | 0.878 | 0.758 | 19 / 19 |
| 과거만 경로 | **0.879** | **0.801** | 14 / 15 (최대 −0.05) |

## 결론
누적 최댓값은 오류 고착(과대예측 증가). 미래까지 봐도 이득 +0.001~0.005 → **남은 오류는 프레임 튐이 아니라 경계 지연**. 단조 후처리는 우선순위 낮음.
