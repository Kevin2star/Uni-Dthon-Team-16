## 결론
- 이미지만으로는 **지금까지 최고 (0.734 → 0.767)**. 새 12개만으로 기존 77개와 같은 성능.
- 하지만 센서와 합치면 이득 없음. 개선이 **1→2 경계(노이즈)**에 몰려 있는데, 그 경계는 센서가 이미 거의 완벽(S1 F1 1.0).
- 2→3, 4→5를 가르는 이미지 신호는 여전히 부족 → 다음은 이 두 경계에 특화된 피처나 학습이 필요.
