Uni-DTHON · 배터리 열폭주 6단계 분류

베이스라인 v7, 어디서 맞고 어디서 틀리나

센서 5개 + 열화상 밝기 통계 6개 + 과거 30초 시계열 피처(개)로 학습한 로지스틱 회귀(class_weight=None)의 결과입니다. Train으로 학습하고 Validation 19개 실험으로 평가했습니다.

    단계별 성능

    1·3단계는 잘 맞고, 4·5·6단계가 점수를 깎는다

    Macro F1은 6개 단계 F1의 단순 평균이라, 샘플이 적은 4·5·6단계가 전체 점수에 1/6씩 똑같이 반영됩니다.

    단계별 Precision · Recall · F1

    혼동 행렬 (행 = 실제, 칸 색 = 행 기준 비율)

    실험별 결과

    Validation 19개 실험: 실제 단계 vs 예측 단계

    각 실험의 위 띠가 실제 단계, 아래 띠가 예측입니다. 시간은 왼쪽에서 오른쪽, 길이는 실험마다 맞춰 늘렸습니다. F1이 낮은 순으로 정렬했습니다.

    이미지로 보는 실패

    헷갈리는 쌍

    가장 많이 틀린 4가지 경우

    실제 단계와 예측 단계가 다른 Validation 샘플을 서로 다른 실험에서 골랐습니다. 이미지 아래 숫자는 관측 시점(초)과 모델 확신도입니다.

    맞힌 예시

    단계별로 맞힌 열화상

    색은 절대 온도가 아니라 이미지마다 따로 정규화된 것으로 보입니다. 1단계에도 빨간색이 나오는 이유입니다. 밝기 통계보다 열이 퍼진 모양이 단서가 될 가능성이 큽니다.
